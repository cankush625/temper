Run `temper learn --now`. When this turn ends, the learning hook starts a background reflection
over everything since the last one: a propose-only reflector reads the redacted episode and the
learned-skill index, and the promoter lands or rejects each proposal. The next session's start
reports what landed and what was rejected.

Do not write or edit skill files yourself, and do not describe a skill as learned — you will not
see the outcome in this session. Say only that a reflection was requested.
